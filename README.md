# 📊 Customer Behavior Analysis

## 📌 Project Overview

This project focuses on analyzing customer shopping behavior to identify purchasing patterns, customer preferences, spending trends, and factors influencing buying decisions.

The goal is to transform raw customer data into meaningful business insights that help businesses improve customer satisfaction, optimize marketing strategies, and make data-driven decisions.

## 🎯 Project Objectives

- Analyze customer purchasing patterns and spending behavior.
- Understand customer demographics and product preferences.
- Evaluate the impact of discounts on purchasing decisions.
- Compare subscription and non-subscription customers.
- Identify customer segments based on purchase history.
- Generate actionable business insights.

## 🛠️ Tools & Technologies

- **Python:** Data cleaning, preprocessing, and exploratory data analysis (EDA).
- **Pandas & NumPy:** Data manipulation and analysis.
- **SQL:** Querying data and answering business questions.
- **Power BI:** Interactive dashboards and data visualization.
- **Jupyter Notebook:** Data analysis and experimentation.
- **Git & GitHub:** Version control and project management.

## 🔍 Project Workflow

1. **Data Collection:** Load the customer shopping dataset.
2. **Data Cleaning:** Handle missing values, duplicates, and inconsistent data.
3. **Exploratory Data Analysis:** Explore customer demographics, purchase patterns, and spending trends.
4. **SQL Analysis:** Write queries to answer business-related questions.
5. **Data Visualization:** Create charts and dashboards to communicate findings.
6. **Business Insights:** Develop recommendations based on the analysis.

## ❓ Business Questions

- Which product categories are most popular?
- How do customer demographics influence purchasing behavior?
- Do discounts affect customer spending?
- How does subscription status relate to purchasing behavior?
- Which customers make repeat purchases?
- What factors can help improve customer retention?

## 📈 Key Outcomes

- Identified patterns in customer purchasing behavior.
- Explored customer segmentation and purchase frequency.
- Analyzed relationships between discounts, subscriptions, and spending.
- Developed a foundation for data-driven marketing and customer retention strategies.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/nishant1800/Customer-Behavior-Analysis.git
cd Customer-Behavior-Analysis
```

### 2. Install Dependencies

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 3. Run the Analysis

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the relevant notebook and execute the cells.

*Note: SQL and Power BI steps depend on the database scripts, dashboard files, and other resources included in the repository.*
